## 🧪 Projeto em destaque

### [📂 Portfolio_QA](https://github.com/Pietro19/Portfolio_QA) · Testes E2E (Cypress + Playwright) e de API (Postman)

[![CI](https://github.com/Pietro19/Portfolio_QA/actions/workflows/ci.yml/badge.svg)](https://github.com/Pietro19/Portfolio_QA/actions/workflows/ci.yml)

| | |
|---|---|
| **134 testes E2E** | 104 em Cypress (JavaScript) + 30 em Playwright (TypeScript) |
| **64 asserções de API** | 27 requisições Postman/Newman na API REST ServeRest |
| **Aplicações reais** | Scoder, Inatel e SauceDemo (UI) + ServeRest (API) |
| **CI/CD** | GitHub Actions com 3 jobs paralelos, execução diária agendada e relatórios HTML, vídeos e traces como artefatos |

- 🎭 **Playwright:** login positivo/negativo, UI, usabilidade, segurança, sessão e performance
- 🌲 **Cypress:** navegação, formulários, conteúdo, carrinho, fluxo de compra E2E e responsividade
- 📬 **Postman/Newman:** CRUD de usuários, produtos e carrinhos, autenticação e regras de negócio, com dados criados e limpos a cada execução
- 🔁 **Mesma suíte nas duas ferramentas** (Inatel), permitindo comparar as abordagens lado a lado

👉 **[Ver o repositório e o pipeline](https://github.com/Pietro19/Portfolio_QA)**
